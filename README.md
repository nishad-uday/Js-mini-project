# 🚀 JavaScript Assignments & Product Inventory Dashboard

A practical JavaScript project containing **6 core JavaScript assignments** and a final **Interactive Product Inventory & Analytics Dashboard**.

This project covers JavaScript fundamentals such as variables, data types, operators, conditional statements, loops, functions, scope, arrays, objects, and array methods.

The final mini project combines these concepts into an interactive browser-based inventory dashboard.

# 🚀 Mini Project

## Interactive Product Inventory & Analytics Dashboard

The final project combines the major JavaScript concepts learned throughout the assignments into an interactive inventory dashboard.

### ✨ Features

- ➕ Add new products
- 💰 Enter product price
- 📊 Display total number of products
- 💵 Calculate total inventory value
- 🏷️ Automatically assign product categories
- 📋 Display products in an inventory table
- ✅ Validate product input
- 🔄 Dynamically update the dashboard
- 📱 Browser-based interface
- 🌐 Deployed using Vercel

---

# 🏷️ Product Categories

The application automatically categorizes products according to their price.

| Price | Category |
|---|---|
| Below $50 | Budget |
| $50 – $199 | Standard |
| $200 or above | Premium |

### Example

```text
Laptop  → $800 → Premium
Mouse   → $25  → Budget
Monitor → $150 → Standard
```

---

# 🧮 Dashboard Analytics

The dashboard calculates the total inventory value using JavaScript array operations.

Example:

```text
Laptop  = $800
Mouse   = $25
Monitor = $150

Total Inventory Value = $975
```
